# 第 1 阶段实施计划

依据用户本次消息及 MCU_PC_Monitor_Codex_Spec.md，仅实现串口原始数据监控。

1. 创建独立项目、依赖清单和测试；不改动现有 MCU 示例。
2. serial_manager.py：扫描端口；QThread 内打开、读取、关闭串口；Signal 通知状态、原始文本及错误。读取超时 100ms，停止使用中断请求，不在 GUI 等待线程。
3. main_window.py：COM、波特率、刷新、连接/断开、原始文本、清空和状态栏。串口忙时锁定设置；关闭窗口先请求停止，线程结束后关闭。
4. main.py：只创建应用和主窗口。
5. 自动测试分段 UTF-8、无数据停止、打开失败、读取异常、重连、GUI 收到数据和关闭清理；启动真实窗口验证。

验证关注：蓝牙驱动报错、无换行长数据、端口被占用、快速断开、连接中退出。
后续模块按后续阶段创建，config/ 与 data/ 先预留。
